# Neon Snake 🐍✨

A fun and cool browser-based Snake game with neon aesthetics!

## How to Play

1. Open `index.html` in any modern browser (or host it on GitHub Pages).
2. Use the **Arrow Keys** to control the snake.
3. Eat the pink food to grow and score points.
4. Avoid hitting the walls or yourself!

## Features

- Neon glow effects
- Smooth gameplay
- Score tracking
- Restart button
- Fully responsive canvas

## Play Now

If you enable GitHub Pages on this repo, you can play it live at:  
`https://sammiee2015lulz.github.io/fun-cool-game/`

Made with pure HTML, CSS, and JavaScript — no dependencies!
